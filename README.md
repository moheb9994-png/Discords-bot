# Soork Store v2

## المزايا
- متجر ومنتجات.
- إنشاء روم طلب خاص.
- عرض بيانات تحويل الراجحي.
- زر إرسال إثبات الدفع.
- رفع صورة/ملف إثبات داخل روم الطلب.
- زر تأكيد الدفع للإدارة.
- زر رفض الإثبات للإدارة.
- زر إغلاق الطلب.

## الإعداد
1. `npm install`
2. انسخ `.env.example` إلى `.env`
3. ضع Token البوت و IDs.
4. ضع بيانات التحويل في `.env`.
5. عدّل `data/products.json`.
6. `npm start`

مهم: البوت لا يتحقق آليًا من وصول الحوالة في هذا الإصدار؛ التأكيد يدوي من الإدارة. الراجحي يوفر منتجات تكامل ومدفوعات إلكترونية رسمية للشركات، ويمكن لاحقًا بناء تحقق آلي عبر تكامل رسمي إذا توفرت صلاحيات/اشتراك مناسب.
